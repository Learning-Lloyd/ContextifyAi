# Dataset sources and attribution

## MS-LaTTE

- Source: Microsoft Research, [MS-LaTTE repository](https://github.com/microsoft/MS-LaTTE) and [paper page](https://www.microsoft.com/en-us/research/publication/ms-latte-a-dataset-of-where-and-when-to-do-tasks-are-completed/).
- Supplied file: `original/MS-LaTTE.json`.
- Scope: 10,101 anonymized task titles and list titles with multiple human judgements about likely task location and time.
- Dataset license: the repository includes the Community Data License Agreement Permissive 2.0 for the dataset. The repository's code license is separate.
- Citation: Jauhar, S. K., Chandrasekaran, N., Gamon, M., & White, R. W. (2022). “MS-LaTTE: A Dataset of Where and When To-do Tasks are Completed.” Proceedings of LREC 2022, pp. 5393–5403. The repository also provides BibTeX for the 2021 preprint, arXiv:2111.06902.

## Contextify scoring validation examples
