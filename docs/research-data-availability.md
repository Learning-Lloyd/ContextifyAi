# Research dataset availability

The public Contextify project currently provides the scoring-validation examples and the independently usable MS-LaTTE context dataset. Dataset records remain separate from personal tasks and from the official priority calculation.

A previously considered third-party dataset was removed from the application and from the cleaned Git history because its source and reuse permissions were not verified. The public application has no endpoint, UI selector, importer, or model integration for that source. A private backup is retained separately as a temporary archival copy; its presence does not establish reuse rights or authorize distribution.

The official Contextify task ranking remains the deterministic formula: Importance 40%, Urgency 30%, Time Availability 20%, and Workload 10%. MS-LaTTE supports supplementary task context research only. The synthetic survey dataset supports the experimental priority model and remains explicitly identified as synthetic; neither replaces the official ranking.
