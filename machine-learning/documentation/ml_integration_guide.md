# ML integration guide

## Integrated prediction

Two optional predictions are available in the authenticated Decision Lab. The MS-LaTTE likely-location model runs in Laravel through `POST /api/research-context/predict`; it returns an optional context label. The synthetic task-priority prototype runs through a local FastAPI service; Laravel's authenticated `POST /api/decision-lab/predict-experimental-priority` scopes selected task IDs to the signed-in user, calls the localhost ML service, and returns the predicted category plus a separate rule-based next-step suggestion using that category and urgency.

The UI identifies the priority output as an experimental synthetic-data prediction. Its next-step suggestion is generated by transparent templates from the predicted category and urgency; it is not generative-AI text. Neither output is saved into task records, displays confidence, nor changes the deterministic score or task order. The location predictions are not saved as task location or actual user preference. No confidence is displayed for either model.

## Not integrated

- MS-LaTTE time-of-day: poor recall for rare night targets and risk of confusing contextual preference with a real deadline.
- A real-world Contextify priority model: no independently reviewed real-task labels are available. The synthetic-data prototype is research-only and not validated for real students. The formula remains authoritative.

## Retraining and model replacement

Run the import and training commands in `ml_training_methodology.md`. Training is offline and explicit; task creation never triggers training. Each trained artifact includes a version, dataset digest, training date, feature description, split sizes, and algorithm. `datasets/models/model_registry.json` records artifact hashes, evaluation metrics, and deployment status. Review the new report and compare it with the currently integrated version before replacing the application artifact. The system has no automatic promotion or online learning.

The experimental priority service requires the pinned local Python environment and a separate Uvicorn process on `127.0.0.1:8010`. If that process is down, the Decision Lab shows an unavailable message and continues using the formula-based analysis. See `task_priority_training_report.md` for its synthetic-only performance and limitations.

Never include private user task data without the required consent and approved research protocol.
